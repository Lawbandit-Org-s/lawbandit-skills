# Lawbandit Skills

Free [Claude](https://claude.ai) skills made by **Lawbandit** for law students, professors, and legal professionals.

A skill is a folder of instructions and tools that teaches Claude how to do a specific task well, like turning your outline into an exam-ready crib sheet. Download a skill, add it to Claude, and ask for what you need.

## How to install a skill

**Claude (web or desktop app)**
1. Download the skill's `.zip` from the table above.
2. In Claude, go to **Settings → Capabilities → Skills** and upload the zip. Code execution must be turned on.
3. Start a new chat and ask for the task, for example: *"Make a crib sheet for my Torts final."*

**Claude Code**
1. Unzip the file.
2. Move the skill folder into `~/.claude/skills/` (Mac/Linux) or `C:\Users\<you>\.claude\skills\` (Windows).
3. Start Claude Code and ask for the task.

Each skill folder has its own `README.md` with details and any tools it needs.
